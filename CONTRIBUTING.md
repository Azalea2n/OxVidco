# Panduan Kontribusi OxVidco

Terima kasih telah tertarik untuk berkontribusi pada OxVidco! Panduan ini akan membantu Anda memulai dengan lancar.

## 🛠️ Memulai

1. **Fork** repositori ini
2. **Clone** repositori hasil fork:
   ```bash
   git clone https://github.com/username-kamu/OxVidco.git
   cd OxVidco
   ```
3. **Buat branch** untuk fitur/perbaikan:
   ```bash
   git checkout -b fitur/nama-fitur
   ```
4. **Commit** perubahan Anda:
   ```bash
   git commit -m "feat: tambahkan fitur baru"
   ```
5. **Push** ke branch Anda:
   ```bash
   git push origin fitur/nama-fitur
   ```
6. Buat **Pull Request**

## 📝 Standar Kode

- Gunakan konvensi penamaan C# yang konsisten
- Dokumentasikan kode dengan komentar yang jelas
- Tulis pengujian untuk fitur baru
- Pastikan semua pengujian berhasil

## 🐛 Melaporkan Bug

1. Periksa [daftar issue](https://github.com/Azalea2n/OxVidco/issues) yang ada
2. Jika bug belum dilaporkan, buat issue baru
3. Sertakan:
   - Langkah-langkah untuk mereproduksi bug
   - Perilaku yang diharapkan
   - Screenshot jika memungkinkan
   - Versi aplikasi dan sistem operasi

## ✨ Mengusulkan Fitur Baru

1. Buat issue baru dengan label "enhancement"
2. Jelaskan mengapa fitur ini bermanfaat
3. Sertakan contoh kasus penggunaan

## 🧪 Pengujian

- Pastikan untuk menjalankan pengujian sebelum mengirim PR
- Tambahkan pengujian untuk kode baru yang Anda tulis

## 📄 Lisensi

Dengan berkontribusi, Anda menyetujui bahwa kontribusi Anda akan dilisensikan di bawah Lisensi MIT.

## 🙏 Ucapan Terima Kasih

Terima kasih telah meluangkan waktu untuk berkontribusi pada OxVidco! 🎉
